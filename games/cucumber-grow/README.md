# 오이키우기 MVP

## 게임 개요

오이키우기는 여러 텃밭의 오이를 각각 심고, 물주기와 시설의 자동 경험치로
성장시킨 뒤 캐릭터를 직접 눌러 수확하는 모바일 중심 육성형 웹게임이다. 현재
말린오이닷컴 저장소 안에 있지만 기존 사이트, 말린오이캘린더, Android·iOS 앱과
코드를 공유하지 않는 독립 프로젝트 표면으로 구성한다.

## 현재 구현 기능

- 상단 고정 HUD 아래에 이어지는 탑다운 잔디·흙밭 화면과 세로 스크롤
- 모바일 2열 텃밭 그리드와 간격 없이 이어지는 공통 외곽 표면
- 홀수 개 마지막 텃밭을 다음 행 왼쪽부터 잇는 확장형 배치
- 텃밭 하나당 2×2로 배치한 독립 작물 슬롯 4개
- 메뉴 → 상점에서 정가 100오이인 텃밭을 임시 무료 모드로 반복 구매
- 빈 슬롯 직접 터치로 심기, 성장 중 슬롯 터치로 물주기, 성숙 슬롯 터치로 수확
- 슬롯별 현재 성장 단계 XP 막대와 `aria-label`·`progressbar` 접근성 정보
- 실제 새싹 표시 크기를 따르는 물뿌리개와 함께 비례 확대되는 물줄기·물방울
- 성장 단계별 실제 캐릭터 영역의 잎·머리를 향하는 물 도착점과 `1XP` 효과
- 슬롯별 심기·2단계 진화·수확 모션과 전환 잠금
- 빈 슬롯의 잔잔한 파동과 수확 가능 슬롯의 빛·바운스 유도 효과
- 새싹(0 XP) → 애기오이(15 XP) → 어른오이(35 XP) → 수확 가능(50 XP)
- 누적 저장 XP는 호환성을 위해 유지하되 막대와 성장 판정은 단계별 15·20·15 XP 사용
- 작물 하나 수확당 보유 오이 1개 지급
- 시설이 생산한 전역 XP 총량의 슬롯 라운드로빈 배분
- 최대 8시간 오프라인 XP의 동일 라운드로빈 배분
- 저장 스키마 v2와 기존 v1 단일 작물 저장의 멱등 마이그레이션
- 페이지 숨김·이탈·자동 저장과 재실행 시 저장 복원
- 빠른 포인터/합성 클릭의 중복 실행 방지
- 화면 밖 텃밭 반복 애니메이션 일시정지와 `prefers-reduced-motion` 대응

## 이번 단계에서 열지 않은 기능

- 비닐하우스형 텃밭, 알람, 상세 튜토리얼
- 서버 저장, 계정 로그인, 여러 기기 동기화
- 서버 시간 검증과 치팅 방지
- 퀘스트, 업적, 환생, 광고, 인앱결제
- 독립 Android·iOS 프로젝트와 네이티브 기능

## 저장 데이터

호환성을 위해 기존 로컬 저장소 키를 유지한다.

```text
mallinoi_cucumber_grow_save_v1
```

현재 저장 스키마:

```javascript
{
  saveVersion: 2,
  cucumbers: 0,
  totalEarned: 0,
  touchYield: 1,
  harvestCount: 0,
  facilities: {
    "small-garden": 0,
    "greenhouse": 0,
    "watering-system": 0,
    "smart-farm": 0,
    "processing-factory": 0
  },
  perSecond: 0,
  plots: [
    {
      plotId: "garden-1",
      type: "garden",
      slots: [
        {
          slotId: "garden-1-slot-1",
          isPlanted: false,
          xp: 0,
          growthStageId: "sprout"
        }
        // 총 4개
      ]
    }
  ],
  hasClaimedFreeGarden: true,
  nextPlotSequence: 2,
  autoXpCursor: 0,
  automaticXpRemainder: 0,
  lastSavedAt: 0,
  startedAt: 0,
  settings: {}
}
```

신규 이용자는 `plots: []`, `hasClaimedFreeGarden: false`로 시작한다. 텃밭 정가는
`GAME_CONFIG.gardenPurchase.listPrice`의 100오이이고, 현재는
`temporaryFree: true`라 실제 차감액이 0이다. 상점에서 구매할 때마다 고유한 텃밭
하나와 빈 슬롯 4개를 추가하며 무료 모드에서는 보유 오이를 차감하지 않는다.
`hasClaimedFreeGarden`은 이전 저장 호환을 위해 유지하지만 반복 구매를 제한하지
않는다. 무료 모드를 끄면 같은 구매 로직이 잔액 100오이 이상을 확인하고 정가를
차감한다. 구매 저장이 실패하면 재화·텃밭·다음 순번을 모두 구매 전으로 되돌린다.

### v1 마이그레이션

`growthExperience`, `growthStageId`, `isPlanted`를 사용하는 단일 작물 저장은 첫
로드에서 다음과 같이 변환한다.

- 첫 번째 텃밭을 보유한 상태로 전환
- 기존 작물을 첫 텃밭의 첫 슬롯에 배치
- 기존 빈 밭이면 첫 슬롯도 빈 상태로 유지
- 나머지 세 슬롯은 빈 상태로 생성
- 보유 오이, 누적 재화, 물주기 XP, 시설, 수확 횟수, 저장·시작 시각, 설정 보존
- 무료 텃밭 혜택은 이미 사용한 것으로 표시

변환 결과를 v2로 저장하므로 반복 새로고침해도 텃밭을 다시 만들지 않는다. v2를
불러올 때도 텃밭과 슬롯 ID 중복을 정규화하고, 텃밭마다 슬롯을 정확히 4개로
보완한다. `perSecond`와 슬롯의 `growthStageId`는 시설과 XP에서 다시 계산한다.
누적 XP가 15·35인 저장은 각각 다음 단계의 표시 XP 0으로 복원하며, 기준을
초과한 저장값은 초과분을 현재 단계 XP로 표시한다.

## 자동·오프라인 XP 규칙

시설의 기존 전체 생산량을 작물 수만큼 곱하지 않는다.

1. 경과 시간 × 시설 초당 생산량으로 전역 XP 총량을 한 번 계산한다.
2. 1 미만 소수는 `automaticXpRemainder`에 보관한다.
3. 확정된 정수 XP만 텃밭·슬롯의 안정적인 저장 순서로 라운드로빈 배분한다.
4. 비어 있거나 50 XP에 도달한 슬롯은 건너뛴다.
5. 한 슬롯이 성숙하면 남은 XP를 다음 대상 슬롯에 배분한다.
6. 대상 슬롯이 하나면 기존 단일 작물처럼 그 슬롯이 전체 XP를 받는다.
7. 대상이 하나도 없으면 XP를 작물에 지급하거나 다음 심기까지 보관하지 않는다.

오프라인 보상도 같은 배분기를 사용한다. 마지막 저장 시각과 현재 시각의 차이는
완료된 초로 계산하고 최대 8시간까지만 인정한다. 적용 직후 계산 시각을 현재로
전진시켜 같은 구간을 중복 지급하지 않는다.

## 입력과 효과

- `pointerdown`을 기본 포인터 입력으로 사용하고 뒤따르는 `click`은 무시한다.
- 키보드·보조기기의 합성 `click`은 슬롯 버튼에서 별도로 처리한다.
- 심기와 수확 전환 잠금은 슬롯 키 단위이므로 다른 슬롯은 계속 조작할 수 있다.
- 심기 입력은 XP를 주지 않으며, 수확 입력은 같은 이벤트에서 재심기로 이어지지
  않는다.
- XP와 파티클 레이어는 각 슬롯 DOM 안에 생성한다.
- 물 레이어는 확대 효과가 슬롯 경계에서 잘리지 않도록 텃밭 월드 전체를 공통 좌표
  영역으로 사용하되 슬롯별 효과 노드와 정리 상태는 독립적으로 유지한다.
- 여러 슬롯의 효과와 정리 타이머는 서로 공유하지 않는다.
- 물 도착점은 작물 이미지의 실제 표시 사각형과 단계별 머리·잎 기준점으로 구한다.
- 물뿌리개 크기는 실제 캐릭터 높이를 40~64px 안전 범위에서 따르고 물 스프라이트는
  같은 크기 비율로 계산한다.
- 물뿌리개는 도착점 위쪽에 두고 물줄기를 대각선 아래로 연결하며, 텃밭의 좌우 슬롯
  열에 따라 분사 방향을 반전한다. 스크롤·리사이즈 중에는 현재 캐릭터 위치로 다시
  계산하고 종료 시 임시 스타일과 데이터 속성을 제거한다.

## 연속 텃밭 표면

- 저장·구매 단위는 기존과 동일한 텃밭 1개당 슬롯 4개이며 `plotId`, `slotId`, 순서를
  변경하지 않는다.
- 렌더링 시 각 텃밭의 상하좌우 이웃을 계산해 바깥쪽 변에만 녹색·갈색 프레임과
  둥근 모서리를 표시한다.
- 텃밭 그리드의 행·열 간격은 0이고 내부 접합부에는 한 겹의 얇은 슬롯 구분만 둔다.
- 공통 그림자는 전체 `.plot-list`에 한 번만 적용하고 개별 텃밭 그림자는 제거한다.
- 3번째·5번째처럼 홀수 행에 남는 텃밭은 가운데 정렬하지 않고 왼쪽 첫 칸에서
  시작한다.

## 기존 프로젝트와의 격리

- 게임은 `games/cucumber-grow/` 밖의 HTML, CSS, JavaScript, 이미지, 음원,
  Supabase 코드를 import하거나 참조하지 않는다.
- 기존 루트 HTML과 서비스 메뉴에 게임 링크를 추가하지 않았다.
- 기존 공용 CSS와 `tokens.css`를 불러오지 않는다.
- Supabase 클라이언트, 로그인, 피클, 사이트 상점, 인벤토리를 사용하지 않는다.
- 게임 파일을 `www/`, `android/`, `ios/`에 복사하지 않는다.
- SQL, 테이블, RPC를 만들거나 수정하지 않는다.

기존 Capacitor 설정의 `webDir`은 `www`이고 준비 스크립트는 `games/`를 복사하지
않으므로, 이 게임 변경을 위해 `prepare:capacitor`, `cap sync`, Android·iOS
빌드를 실행하지 않는다.

## 캐시 버전

2026-08-01 배포 준비에서 `SITE_VERSION`과 다음 게임 자산 쿼리 버전을
`20260801-01`로 함께 갱신했다.

- `css/game.css?v=...`
- `js/main.js?v=...`

변경된 `ui-renderer.js`를 불러오는 `js/main.js`의 내부 import 쿼리도 같은
버전으로 갱신했다. 변경하지 않은 `crop-transition.js`와 `xp-gain-effect.js`의
내부 import 쿼리는 기존 버전을 유지한다.

## 수동 확인 항목

- 390×844, 844×390, 1440×900에서 가로 넘침과 안전 영역 겹침이 없는지
- 신규 진입에 텃밭이 없고 상점에 `정가 100오이 · 현재 무료`가 표시되는지
- 빠른 연속 입력 한 묶음이 중복되지 않고, 구매를 다시 누를 때마다 텃밭이 정확히
  하나씩 추가되는지
- 무료 구매 전후 보유 오이가 같고 다섯 개 이상 구매·새로고침 복원이 되는지
- 한 텃밭의 네 슬롯이 각각 심기·물주기·진화·수확되는지
- 심기 입력에서 XP가 오르지 않고 다음 입력부터 대상 슬롯만 오르는지
- 각 캐릭터 머리 위 XP 막대와 모든 슬롯의 물줄기가 새싹 잎·애기오이 잎·어른오이
  머리에 닿는지
- 새싹 0/14 XP, 애기오이 15/34 XP, 어른오이 35/50 XP에서 막대가 각각 현재
  단계의 0부터 차고 성장 직후 다시 0으로 보이는지
- 물뿌리개가 새싹 캐릭터와 비슷한 크기이고 물줄기·물방울도 함께 확대되는지
- 성숙 캐릭터 직접 터치 시 해당 슬롯만 비고 보유 오이가 1개 늘어나는지
- 여러 텃밭 사이의 행·열 간격, 중복 외곽선·둥근 모서리·그림자가 사라지고 하나의
  연속된 표면처럼 보이는지
- 3번째·5번째 텃밭이 가운데가 아니라 다음 행 왼쪽에서 이어지는지
- 320px, 390px, 430px에서 가로 넘침 없이 마지막 텃밭까지 스크롤되는지
- 메뉴와 상점 입력이 아래 슬롯에 전달되지 않는지
- 화면 밖 텃밭의 반복 애니메이션이 일시정지되는지
- 개발자 도구 콘솔에 오류, 경고, 누락 자산 요청이 없는지
