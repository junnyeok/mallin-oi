말린오이닷컴

개인정보처리방침

말린오이닷컴 및 말린오이 캘린더 앱은 사용자의 개인정보를 중요하게 생각합니다. 이 방침은 말린오이닷컴 웹사이트와 말린오이 캘린더 앱에 적용됩니다.

시행일: 2026년 10월 18일

1. 처리하는 개인정보 항목

서비스 제공을 위해 아래 정보를 처리할 수 있습니다.

  • 이메일 주소
  • 사용자 ID 또는 인증 식별자
  • 닉네임
  • 소셜 로그인 선택 시: 로그인 제공자(Google, 카카오, Apple), 제공자별 계정 식별자, 제공자가 전달하는 이메일과 이메일 인증 여부. 이름, 연락처 목록, 생년월일은 소셜 로그인 필수 항목으로 요청하지 않습니다.
  • 계정 연결·해제 시각, 본인 확인 결과, 가입 시 약관 및 개인정보 안내 동의 정보
  • 프로필 이미지 등 사용자가 직접 등록한 프로필 정보
  • 사용자가 작성한 게시글, 댓글, 문의, Q&A 등 서비스 이용 콘텐츠
  • 사용자가 입력한 캘린더 일정, 메모, 카테고리와 정렬 순서, 반복근무 정보
  • 기기에 저장하는 알람 예약, 위젯 표시 데이터, 라이트·다크모드 설정
  • 서비스 이용 기록, 접속 기록, 오류 기록 등 운영에 필요한 기술 정보

2. 개인정보 처리 목적

  • 회원가입 및 로그인
  • 사용자 식별, 소셜 로그인 및 기존 회원 계정 연결·해제
  • 캘린더 일정 저장 및 동기화
  • 게시글, 댓글, 문의, Q&A 기능 제공
  • 사용자가 설정한 일정 알람, 위젯 표시 및 화면 설정 유지
  • 오류 확인, 보안, 부정 이용 방지
  • 앱 심사 및 고객 지원 대응

3. 개인정보 보관 기간

개인정보는 회원 탈퇴 또는 삭제 요청 시까지 보관할 수 있습니다. 사용자가 직접 삭제한 콘텐츠는 삭제 처리하며, 법령상 보관이 필요한 경우에는 해당 법령에서 정한 기간 동안 보관할 수 있습니다.

  • 소셜 계정 식별자는 연결 유지 기간 동안 보관하고 연결 해제 또는 회원 탈퇴 시 삭제합니다. 연결 이력에서 회원을 식별하는 정보는 회원 탈퇴 시 제거합니다.
  • 로그인 진행 중의 임시 인증 요청은 5분간 유효합니다. 만료 후 하루가 지난 임시 요청과 오래된 요청 횟수 제한 기록은 이후 인증 요청 처리 과정에서 정리합니다.
  • Apple 연결 해제에 필요한 인증 값은 서버에서 암호화하여 보관합니다. Apple의 해제 처리가 완료되면 삭제하며, 통신 실패 시 처리를 재시도할 때까지 보관합니다.
  • Apple·카카오의 계정 변경 알림은 위조·중복·지연 처리를 방지하기 위해 제공자 식별자, 알림 종류와 시각을 보관합니다. 수신 후 30일이 지난 기록은 다음 알림 처리 시 정리합니다. 외부에서 연결을 해제하면 해당 소셜 연결을 해제하고, Apple 이메일 전달 상태를 반영합니다. 말린오이 회원 탈퇴는 별도의 탈퇴 절차를 따릅니다.

4. 개인정보 제3자 제공

말린오이닷컴은 사용자의 개인정보를 원칙적으로 제3자에게 판매하거나 제공하지 않습니다. 다만 법령에 따른 요청이 있거나 사용자의 동의가 있는 경우에는 예외적으로 제공될 수 있습니다.

5. 개인정보 처리 위탁 및 외부 서비스

서비스 제공을 위해 아래 외부 서비스를 사용할 수 있습니다.

  • Supabase: 회원 인증, 데이터베이스, 파일 저장 등 백엔드 서비스
  • Resend: 회원가입 확인, 본인 확인, 비밀번호 재설정 등 인증메일 발송
  • GitHub Pages 또는 현재 호스팅 서비스: 웹사이트 정적 파일 제공
  • Google Play / Apple App Store: 앱 배포 및 스토어 운영
  • Google, 카카오, Apple: 사용자가 선택한 소셜 계정의 본인 인증 및 연결 해제. 선택한 제공자의 인증 화면으로 이동하며 해당 제공자의 개인정보처리방침도 적용됩니다. 말린오이 계정의 캘린더 일정, 게시글, 피클 잔액은 소셜 로그인 요청에 포함하지 않습니다.

소셜 로그인과 기존 계정 연결 안내

  • 소셜 로그인은 선택 기능이며 기존 이메일·비밀번호 로그인도 계속 사용할 수 있습니다. 웹사이트와 캘린더 앱은 같은 회원 계정을 사용합니다.
  • 이메일 주소가 같다는 이유만으로 계정을 자동으로 합치지 않습니다. 기존 계정에 로그인한 뒤 비밀번호 또는 이메일 인증번호로 본인 확인을 하고 연결해야 합니다.
  • 카카오 등에서 인증된 이메일을 받지 못한 경우 사용자가 이메일을 입력하고 인증합니다. Apple의 ‘나의 이메일 가리기’를 선택하면 Apple이 제공하는 비공개 릴레이 주소를 사용합니다.
  • 소셜 제공자의 비밀번호는 해당 제공자의 인증 화면에 입력하며 말린오이닷컴이 수집하지 않습니다. 기존 말린오이 비밀번호를 이용한 본인 확인 입력은 인증 처리에만 사용합니다.
  • 마이페이지의 ‘소셜 계정 연결’에서 연결 상태를 확인하거나 해제할 수 있습니다. 계정 접근을 유지하기 위해 마지막 로그인 수단은 다른 수단을 추가하기 전에는 해제할 수 없습니다.
  • 소셜 연결 해제는 말린오이 회원 탈퇴와 다릅니다. 회원 탈퇴는 웹사이트와 캘린더의 공통 계정에 적용되며, 탈퇴 화면의 삭제 안내를 확인한 뒤 진행할 수 있습니다.

6. 사용자가 직접 공개하는 정보

게시글, 댓글, 프로필 닉네임 등 사용자가 공개 영역에 작성한 정보는 다른 사용자에게 보일 수 있습니다. 캘린더 일정은 계정별 개인 데이터로, 원칙적으로 다른 사용자에게 공개되지 않습니다. 다만 사용자가 캘린더 그룹의 공유·백업·복사 기능으로 전달한 일정은 해당 그룹의 권한과 사용자가 선택한 공유 범위에 따라 다른 구성원에게 제공될 수 있습니다.

7. 앱 권한 및 기기 정보

말린오이 캘린더 앱은 기본 캘린더 기능 제공을 위해 사용자가 입력한 일정 데이터를 저장합니다. 현재 위치정보, 연락처, 카메라, 마이크, 건강정보, 금융정보는 필수 권한으로 수집하지 않습니다. 일정 알람 사용 시 기기의 알림 또는 알람 권한을 요청합니다. 예약한 알람의 제목과 시간은 기기의 운영체제가 처리하며, 권한은 기기 설정에서 변경할 수 있습니다. 사이트의 알람 설정은 앱 설치 안내를 제공하며 사이트에서 일정 알람을 예약하지 않습니다.

위젯을 사용하면 표시할 일정과 화면 설정을 기기에 저장하고 앱과 위젯에서 함께 사용합니다. 위젯에 표시된 일정은 휴대폰 화면을 보는 사람에게 보일 수 있습니다. 다크모드 선택은 기기의 표시 설정으로 저장됩니다.

8. 개인정보 보호 조치

  • 인증 기반 접근
  • 계정별 데이터 분리
  • 운영상 필요한 범위 내 접근
  • 보안 강화를 위한 지속적인 개선

9. 이용자의 권리

사용자는 자신의 정보 수정, 삭제, 회원 탈퇴를 요청할 수 있습니다. 캘린더 일정, 게시글, 댓글 등 사용자가 작성한 콘텐츠는 서비스 기능을 통해 직접 삭제할 수 있으며, 추가 요청은 문의 이메일로 보낼 수 있습니다.

10. 아동 개인정보

말린오이닷컴 및 말린오이 캘린더 앱은 만 14세 미만 아동을 주요 대상으로 하지 않습니다. 필요한 경우 보호자 동의 없이 아동의 개인정보를 의도적으로 수집하지 않습니다.

11. 방침 변경

개인정보처리방침이 변경되는 경우 이 페이지의 시행일 또는 공지사항 등을 통해 안내합니다.
