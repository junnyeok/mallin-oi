# 말린오이닷컴 앱

iOS는 첫 실행과 5분 이상 백그라운드에 있다가 돌아올 때 `https://mallin-oi.com/` 홈을 앱 안에서 연다. 잠깐 다른 앱에 다녀오면 현재 화면을 유지하며, 이전 화면 연결이 끊겼다면 홈을 다시 불러온다. 사이트 화면은 주소창과 브라우저 도구막대 없이 표시된다. 소셜 로그인은 iOS 인증 화면을 열고, 성공하면 앱 안의 사이트로 돌아온다. Android는 시작 화면에서 사이트를 선택하면 Custom Tabs를 열고, 이를 지원하는 브라우저가 없으면 기본 브라우저로 연결된다.

공개 게시글의 제목과 본문 텍스트를 기기에 저장할 수 있다. iOS에서는 게시글의 ‘게시글 저장’을 누른 뒤 사이트 전체서비스의 ‘저장된 글’에서 읽는다. 인터넷에 연결할 수 없을 때는 하단 안내에서 ‘다시 시도’ 또는 ‘저장된 글’을 선택할 수 있다. 브라우저의 같은 버튼은 해당 브라우저에 글을 저장한다. Android 앱의 점 세 개 메뉴에서 ‘오프라인에 저장’을 선택하면 앱 시작 화면의 ‘저장된 글’에서도 읽을 수 있다.

사이트 콘텐츠는 운영 서버에서 읽는다. 상품 데이터는 사이트와 함께 갱신되고, HTML·CSS·JavaScript·이미지는 기존 웹 배포와 캐시 갱신 절차를 따른다. 열린 화면에서 변경 사항을 확인하려면 새로고침한다. 네이티브 코드나 앱 아이콘을 바꿀 때는 앱을 새로 빌드한다.

이 iOS 버전을 배포할 때는 소셜 로그인과 저장된 글 메뉴에 필요한 사이트 JavaScript도 함께 배포한다. 새 웹뷰에서 기존 회원은 처음 한 번 다시 로그인할 수 있다.

## 로컬 실행

- iOS 16 이상. `ios/MallinoiSite.xcodeproj`를 Xcode에서 열고 `MallinoiSite`를 실행한다. 실제 iPhone에서는 Signing & Capabilities에서 이 앱의 개발 팀을 선택한다.
- Android 7.0 이상. Android Studio에서 `android/`를 열고 실행한다. 터미널에서는 JDK 17 이상과 Android SDK 36을 준비하고 `android/`에서 `./gradlew :app:assembleDebug`를 실행한다.
- 두 플랫폼의 앱 식별자는 `com.mallinoi.site`다. 개발용 iOS 설치 파일은 서명에 사용한 프로파일에 등록된 기기에서 사용할 수 있다.
