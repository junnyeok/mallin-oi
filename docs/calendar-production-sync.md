# 캘린더 운영 웹 반영 — 2026-09-26

## 범위

사용자가 운영 말린오이닷컴 캘린더를 현재 앱과 맞추도록 요청했다. `origin/main`의 `c642044b` 위에 캘린더 작업 브랜치 `fcdff897`의 웹 관련 변경만 이식한다. 원래 혼합 작업 폴더는 수정하지 않고 별도 worktree에서 준비한다.

- 자기개발·업무·이벤트 달력의 공휴일 배지와 표시 순서.
- 상세 날짜 오른쪽 일정 추가 버튼, 빈 날짜 선택 후 상세 영역 이동.
- 그룹 연동 중 달력 상단 오른쪽 백업 버튼과 백업 필요 상태 비교.
- 손가락을 따라가는 월 스와이프, 앞뒤 달 미리 준비, 단순 탭·세로 스크롤 유지.
- 날짜·시작/종료 편집 보정, 업무 익일 지정, 그룹/시간 선택의 불필요한 자동 포커스 방지.
- 자기개발 완료 효과음의 앱과 동일한 재생·정리 흐름.
- 웹 전용 알람 안내: 예 → 스토어, 아니오 → 안내창 닫기. 실제 알람은 앱 전용.

운영 main의 상점·이모티콘·프로필·공유 오디오 모듈·사용자 에셋·배포 워크플로는 보존한다. 앱 전용 홈 화면 위젯·네이티브 프로젝트·앱 버전은 이번 웹 요청으로 변경하지 않는다. 웹에 가져온 코드가 공유하는 completion-audio-session.js는 운영 버전의 호환 API를 유지한다.

## 실제 브라우저 확인

테스트 계정으로 자기개발·업무·이벤트 페이지에 로그인하여 공휴일 표시, 세 달력 스와이프, 빈 날짜 선택/상세 영역 이동, 날짜 오른쪽 추가 버튼, 업무 익일 시간 선택을 확인했다. 이벤트 추가 화면의 앱 전용 알람 안내와 아니오 닫기를 확인했다. 데스크톱 1280×720 및 모바일 390×844를 사용했고, 모바일 가로 넘침과 검증 중 콘솔 오류는 없었다.

테스트 계정에는 연결된 캘린더 그룹이 없어 실제 그룹 백업은 실행하지 않았다. 개인 모드에서 백업 버튼이 숨겨지는 화면과 자동 검사로 위치·노출 조건·백업 비교 로직을 확인했다. 일정 생성·수정·삭제는 실행하지 않았다. 닫기 수단이 없는 출석 팝업을 정상 처리하면서 테스트 계정에 10피클이 지급됐고, 구매·장착은 없었다.
