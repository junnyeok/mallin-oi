# 웹 캘린더 알람 안내

2026-09-26 운영 웹 반영. 네이티브 앱의 알람 구현은 `codex/calendar-completion-polish`의 `fcdff897`을 기준으로 한다. 이번 main 변경은 웹 캘린더 기능의 운영 반영이며 앱 빌드·스토어 제출이 아니다.

- 이벤트 일정의 메모 아래 **알람 설정**을 누르면 앱 전용 기능 및 다운로드 안내가 열린다.
- **예**: Android는 Google Play, iPhone·iPad·PC는 App Store의 말린오이 캘린더 페이지를 새 탭으로 연다. 기존 입력은 유지된다.
- **아니오**: 안내창만 닫는다. Escape·바깥 영역 닫기·키보드 포커스 복귀도 지원한다.
- 웹에서는 알람 권한 요청·예약·ICS 다운로드·알람 로컬 저장을 실행하지 않는다. 이전 웹 알람 저장값도 변경하지 않는다.
- 앱에서는 스크롤 메뉴·최대 두 알람·일정 저장 연동을 유지한다. 웹의 URL에 `?app=calendar`가 있어도 네이티브 브리지가 없으면 앱 다운로드 안내가 열린다.

기존 `calendar-app-download-popup.js`의 공식 스토어 주소를 재사용한다. 웹의 실제 일정 저장/삭제와 기기별 앱 알람은 별개이다. 다른 기기에서 변경한 일정에 대한 알람 자동 동기화는 제공하지 않는다.

검증: `node --test tests/calendar-event-alarm.test.mjs`; `tests/fixtures/event-alarm-browser.html`은 실계정 데이터 없이 웹 및 네이티브 모의 브리지를 확인하는 기존 검증 화면이다. 운영 페이지 검증은 배포 보고에 기록한다.
