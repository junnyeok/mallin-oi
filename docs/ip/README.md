# 말린오이 IP 등록 준비

이 디렉터리는 말린오이닷컴의 상표·저작권 등록을 준비하기 위한 조사·증빙 문서 전용 공간이다.

## 작업 범위

- 국내 상표 선행검색 및 출원 후보 정리
- 실제 서비스에 맞는 상품류·지정상품 초안 작성
- 기본오이·오이소년·오이소녀의 저작권 등록 후보 자료 정리
- 저장소 내 캐릭터·로고 자산의 경로, 해시, 확인 가능한 최초 Git 이력 정리
- 생성형 AI 사용 범위와 인간의 창작적 기여 기록
- 제3자 작품을 연상시키는 스킨·의상의 등록 후보 제외 목록 작성

실제 출원 제출, 비용 결제, 대리인 선임과 법적 판단은 이 작업 범위에 포함하지 않는다.

## 역할

### Work

- 특허청, 특허로, KIPRIS, 한국저작권위원회 등 최신 공식 자료 조사
- `말린오이`, `말린오이닷컴`, `MallinOi`와 유사 표장의 선행상표 예비검색
- 문자상표·로고상표 우선순위와 상품류·지정상품 초안 작성
- 대표 캐릭터 3종의 등록 설명자료 초안 작성
- 모든 조사 결과에 검색일, 출처, 판단 근거와 불확실성 표시

### Codex

- 먼저 저장소 구조, 작업 트리와 프로젝트 지침 확인
- 프로덕션 코드와 기존 이미지·음원 파일을 수정하지 않음
- 자산 목록, 파일 SHA-256, 확인 가능한 최초 Git 커밋과 날짜를 문서화
- 제3자 IP 연상 여부와 AI 사용 여부를 자동으로 단정하지 않고 `검토 필요` 또는 `소유자 확인 필요`로 표시
- 결과를 이 브랜치의 `docs/ip/` 아래에만 작성

### ChatGPT 검토

- Work의 행정·법률 조사와 Codex의 저장소 증빙을 대조
- 실제 출원할 표장, 지정상품과 저작물 후보를 준혁과 최종 결정
- 전문가 상담이 필요한 쟁점을 별도로 표시

## 개인정보 주의

이 저장소는 공개 저장소이므로 다음 정보는 절대로 기록하지 않는다.

- 법적 성명
- 주민등록번호
- 자택 주소
- 전화번호
- 출원 계정 정보
- 결제 정보
- 미공개 원본·프롬프트 등 공개하면 곤란한 창작 증빙

출원인 개인정보와 미공개 창작 증빙은 로컬 비공개 폴더 또는 별도 비공개 저장소에서 관리한다.

## 법적 한계

파일 해시와 Git 이력은 관리 및 증빙 보조자료다. 실제 창작자, 창작일, 권리 성립 또는 등록 가능성을 확정하는 자료로 단정하지 않는다. 최종 출원 전에는 공식기관 상담이나 필요한 경우 변리사·변호사의 검토를 받는다.
