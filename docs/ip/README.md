# 말린오이 IP 등록 준비

이 디렉터리는 말린오이닷컴의 상표·저작권 등록을 준비하기 위한 조사·증빙 문서 전용 공간이다.

## 작업 범위

- 국내 상표 선행검색 및 출원 후보 정리
- 실제 서비스에 맞는 상품류·지정상품 초안 작성
- 기본오이·오이소년·오이소녀의 저작권 등록 후보 자료 정리
- 저장소 내 캐릭터·로고 자산의 경로, 해시, 최초 Git 이력 정리
- 생성형 AI 사용 범위와 인간의 창작적 기여 기록
- 제3자 작품을 연상시키는 스킨·의상의 등록 후보 제외 목록 작성

실제 출원 제출, 비용 결제, 대리인 선임, 법적 판단은 이 작업 범위에 포함하지 않는다.

## 역할

### Work

- 특허청, KIPRIS, 한국저작권위원회 등 최신 공식 자료 조사
- `말린오이`, `말린오이닷컴`, `MallinOi` 및 유사 표장의 선행상표 예비검색
- 문자상표·로고상표 우선순위와 상품류·지정상품 초안 작성
- 대표 캐릭터 3종의 등록 설명자료 초안 작성
- 모든 조사 결과에 검색일, 출처, 판단 근거, 불확실성 표시

### Codex

- 먼저 저장소 구조와 프로젝트 지침을 확인
- 프로덕션 코드와 기존 이미지 파일을 수정하지 않음
- 자산 목록, 파일 SHA-256, 최초 Git 커밋 및 날짜를 문서화
- 제3자 IP 연상 여부와 AI 사용 여부는 자동으로 단정하지 않고 `검토 필요`로 표시
- 결과를 이 브랜치의 `docs/ip/` 아래에만 작성

### ChatGPT 검토

- Work의 행정·법률 조사와 Codex의 저장소 증빙을 대조
- 실제 출원할 표장, 지정상품, 저작물 후보를 소유자와 최종 결정
- 전문가 상담이 필요한 쟁점을 별도로 표시

## 개인정보 주의

이 저장소는 공개 저장소이므로 다음 정보는 절대로 기록하지 않는다.

- 법적 성명
- 주민등록번호
- 자택 주소
- 전화번호
- 출원 계정 정보
- 결제 정보

출원인 개인정보와 미공개 창작 증빙은 로컬 비공개 폴더 또는 별도 비공개 저장소에서 관리한다.
