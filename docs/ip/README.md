# 말린오이 IP 증빙 및 문자상표 출원 준비

이 디렉터리는 말린오이닷컴의 IP 관련 저장소 증빙을 보존하고, 현재 진행 중인 `말린오이` 문자상표 국내 출원 준비를 지원하기 위한 문서 전용 공간이다.

## 현재 작업 상태

### 현재 진행

- `말린오이` 일반 문자상표 국내 출원 준비
- 저장소에서 확인되는 표장 사용처, 사용자 노출 위치와 Git 기록 정리

### 현재 보류

- 캐릭터 저작권 등록
- 생성형 AI 캐릭터의 저작권 등록 가능성 판단
- 캐릭터 도형상표 출원
- `images/logo-word.png`를 포함한 로고상표 실제 출원
- 해외상표 출원

기본오이·오이소년·오이소녀 등 52개 자산의 기존 해시와 Git 기록은 삭제하지 않는다. 관련 문서는 향후 인간 창작 리디자인 및 소유자 자료 확보 뒤 다시 검토할 수 있는 보존 자료이며, 현재 신청 대상이나 등록 후보 확정 목록이 아니다.

## 작업 범위

- `말린오이`, `말린오이닷컴`, 영문·도메인 변형과 워드마크 이미지의 저장소 내 사용 조사
- 화면 노출 맥락, 관련 서비스, 현재 상태와 확인 가능한 Git 기록 정리
- `images/logo-word.png`의 규격·해시·참조 경로·동일본 관계 정리
- 소유자가 비공개로 확인할 실제 사용 시점과 운영 사실 질문 정리
- 기존 캐릭터·로고 자산 증빙 52건을 미래 검토자료로 보존

상표 등록 가능성, 유사 여부, 상품류의 최종 선정, 지정상품의 법적 적합성, 상표권 침해 여부와 캐릭터 저작권 성립 여부는 Codex 작업 범위에 포함하지 않는다. 법률·행정 조사는 Work Issue #41에서 별도로 수행한다.

## 개인정보 주의

이 저장소는 공개 저장소이므로 다음 정보는 절대로 기록하지 않는다.

- 법적 성명
- 주민등록번호
- 자택 주소
- 전화번호
- 출원 계정 정보
- 결제 정보
- 미공개 원본·프롬프트 등 공개하면 곤란한 창작 증빙

출원인 개인정보와 미공개 창작 증빙은 로컬 비공개 폴더 또는 별도 비공개 저장소에서 관리한다.

## 법적 한계

파일 해시와 Git 이력은 관리 및 증빙 보조자료다. Git 최초 기록은 최초 상업적 사용일이나 최초 공개일이 아니며, 실제 창작자, 창작일, 권리 성립 또는 등록 가능성을 확정하는 자료로 단정하지 않는다. 최종 출원 전에는 Work #41의 조사와 소유자 자료를 대조하고 필요한 경우 전문가의 검토를 받는다.
