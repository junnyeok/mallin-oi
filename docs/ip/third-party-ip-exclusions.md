## 사용·등록 전 확인 원칙

1. 제3자 캐릭터의 이름·의상·문양·얼굴·소품을 식별할 수 있는 형태로 사용했는지 확인한다.
2. 팬아트·패러디·오마주라는 명칭만으로 상업적 이용이나 권리 등록이 허용된다고 전제하지 않는다.
3. 해당 스킨을 기본오이·오이소년·오이소녀의 대표 등록본 또는 변형본 묶음에 포함하지 않는다.
4. 상품 판매·홍보·앱 배포를 계속할지는 별도의 법률 검토 대상으로 관리한다.
5. 제3자 권리자의 허락이나 라이선스가 있다면 공개 이슈가 아닌 비공개 증빙 폴더에서 원문을 보관한다.

## 추가 검토가 필요한 범위

이번 1차 분리는 이슈에서 명시한 3개 스킨을 중심으로 했다. 나머지 스킨은 `제3자 IP가 아님`을 확정한 것이 아니라, 파일명·저장소 데이터·육안 확인만으로 명시적 연상 대상을 특정하지 않은 상태다. 소유자는 각 스킨 제작 시 참고한 작품·이미지·인물·브랜드가 있었는지 비공개 확인표에 기록해야 한다.
