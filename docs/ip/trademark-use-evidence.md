## 표장 범위

- 핵심 표장: `말린오이`
- 보조 표장: `말린오이닷컴`, `MallinOi`, `images/logo-word.png`
- 함께 조사한 변형: `mallinoi`, `Mallinoi`, `mallin-oi`, `mallin_oi`, `mallin-oi.com`, `mallinoi.com`

`MallinOi`와 `Mallin Oi`의 정확한 철자는 서비스 코드·화면에서 찾지 못했다. 정확한 `MallinOi`는 기존 IP 조사 문서에 조사 대상 표장으로만 나타난다. 소문자 `mallinoi`와 `Mallinoi`는 패키지 ID, URL scheme, 저장 키, 네이티브 클래스·스타일명 등 기술 식별자에서 확인되지만 대부분 사용자 화면 표시는 아니다.

- `docs/ip/`, `.git/`, 잠금 파일, minified 파일, 소스맵과 파일 목록 덤프를 원시 검색 집계에서 제외했다. 새 증빙 문서가 자기 자신을 검색 결과로 늘리는 것을 막기 위한 조치다.
